Privacy policy

Who uses it: only Eirik Broms, for his own Google account.

What it accesses: the Gmail API with the read-only scope gmail.readonly. It cannot send, delete or modify email.

What it does with the data: reads messages about bills, receipts and payments, and stores summaries locally on Eirik's own computers. Nothing is sold, shared with third parties or used for advertising.

Retention and deletion: access can be revoked at any time at myaccount.google.com/permissions; local data is deleted on request.

Google API Services User Data Policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
